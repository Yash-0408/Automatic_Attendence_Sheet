# Automatic Attendance Sheet

This project automates attendance tracking using Excel.  
It records student presence/absence, generates daily reports, and updates a master sheet automatically.

## Features
- ✅ Auto-mark attendance from input data
- 📊 Generate summary reports (present/absent counts)
- 🔄 Update master sheet without manual effort
- 💾 Export attendance logs to Excel/CSV

## Usage
1. Clone the repository
2. Run the script with your class data
3. Attendance will be updated automatically
